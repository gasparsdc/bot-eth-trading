# 📈 Bot ETH Trading

Un bot de trading automatisé pour Ethereum (ETH), développé en JavaScript avec Node.js. 

## 🚀 Fonctionnalités
- Surveillance des prix en temps réel.
- Exécution de transactions (achat/vente) basées sur des indicateurs techniques.
- Mode Paper Trading (simulation) intégré pour tester les stratégies sans risque.

## 🛠️ Prérequis
Pour faire tourner ce projet en local, tu auras besoin de :
- [Node.js](https://nodejs.org/) installé sur ta machine.
- Un compte sur un fournisseur de nœuds RPC (comme Infura ou Alchemy) si nécessaire.
- Un portefeuille (Wallet) avec des fonds de test (Sepolia) ou réels.
